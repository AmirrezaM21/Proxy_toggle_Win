# Proxy_toggle_Win11
A simple batch script using a desktop shortcut to toggle proxy settings on/off.

Setup:
1. Download "proxy_toggle.bat" and the Icons.
2. Place the icons in "C:\Icons" or any custom directory.
3. Create a shortcut from "proxy_toggle.bat" and place it on your Desktop.
4. Edit the directories of the desktop shortcut and the icons to match the files on your system.
5. Done!
   Run it via the shortcut (as administrator). it should toggle to proxy and change the Icon of the shortcut depending on proxy's state.
